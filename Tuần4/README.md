Hướng dẫn chạy bài kiểm thử Selenium

1. Yêu cầu
- Đã cài Python.
- Đã cài Google Chrome.
- Đã cài thư viện Selenium và pytest.

2. Cài đặt thư viện
Mở Terminal tại thư mục dự án và chạy lệnh:

    python -m pip install selenium pytest

3. Chạy bài kiểm thử
Mở Terminal trong VS Code tại thư mục tuan-04, chạy lệnh:

    python -m pytest -v test_smoke.py

4. Kết quả

1 passed: Bài kiểm thử thành công.
1 failed: Bài kiểm thử thất bại, cần kiểm tra lỗi.
